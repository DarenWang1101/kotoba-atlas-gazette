# Changelog

## 0.3.0 — 2026-10-09

- Added six staffing/institution/population ratios with exact-year denominators, coverage and source links.
- Added 1,407 population observations for 201 areas across seven waves; missing areas remain null.
- Added binary/TF–IDF textbook encodings, selectable ratio groups, full model comparison and a reproducible saved clustering default.
- Added population, derived ratio, encoded-feature and clustering evaluation datasets.
- Normalized Benin/Burkina Faso legacy identifiers in generated tables.
- Simplified Open Data navigation to the repository link; existing downloads remain.
- Textbook evidence review remains the 8 October 2026 curation batch; this release does not claim a new PDF audit.

## 0.2.0 — 2026-10-08

- Replaced the limited 12-profile / 129-record index with 1,299 page-linked named-material observations across 123 profiles, with 166 profiles reviewed in their documented scope.
- Added Taiwan's six named titles on PDF p. 7, distinguishing publication mentions from reported higher-education use.
- Expanded Canada, Mexico, other American profiles, Asia/Oceania, Europe and available Africa/Middle East profiles.
- Preserved exact source labels, setting context, page ranges, source hashes and scoped quantitative evidence.
- Included publication/historical mentions with explicit labels instead of hiding them or treating them as current adoption.
- Published review coverage, historical survey tables, a resource manifest, data dictionary and rights statement.
- Sources not retrievable in this pass remain explicitly marked; this is not a claim of complete worldwide textbook coverage.
